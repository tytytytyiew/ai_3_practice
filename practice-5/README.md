## Цель
Классификатор и анализ метрик. Работа выполнена в Jupyter Notebook с последовательными шагами, графиками и выводами.

## Датасет
Breast Cancer Wisconsin dataset из scikit-learn: бинарная классификация benign/malignant. Локальная копия: data/practice5_breast_cancer.csv. Используются predict_proba, ROC/PR, стоимость ошибок и подбор порога. Это учебный набор данных, не инструмент диагностики.

## Запуск
1. Установите Python 3.11 или новее.
2. Откройте корневую папку проекта в VS Code.
3. Установите зависимости: `python -m pip install -r requirements.txt`.
4. Откройте `practice_5.ipynb` и выберите установленное Python-окружение.
5. Выполните **Restart Kernel → Run All**.

Пути к CSV заданы относительно папки ноутбука (`../data/...`), поэтому перемещать файлы данных не нужно. Интернет для загрузки данных не требуется.
