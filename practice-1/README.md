## Цель
Настройка окружения и первый notebook. Работа выполнена в Jupyter Notebook с последовательными шагами, графиками и выводами.

## Датасет
Wine Recognition: 178 образцов вина, химические показатели и класс вина. CSV расположен в data/practice1_wine.csv. В ноутбуке показаны размер, типы, пропуски, статистики и два графика.

## Запуск
1. Установите Python 3.11 или новее.
2. Откройте корневую папку проекта в VS Code.
3. Установите зависимости: `python -m pip install -r requirements.txt`.
4. Откройте `practice_1.ipynb` и выберите установленное Python-окружение.
5. Выполните **Restart Kernel → Run All**.

Пути к CSV заданы относительно папки ноутбука (`../data/...`), поэтому перемещать файлы данных не нужно. Интернет для загрузки данных не требуется.
