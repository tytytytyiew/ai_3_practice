## Цель
Разведочный анализ данных (EDA). Работа выполнена в Jupyter Notebook с последовательными шагами, графиками и выводами.

## Датасет
Retail EDA: 500 учебных записей заказов, числовые и категориальные признаки, специально добавленные пропуски и выбросы. Данные синтетические и предназначены для практики EDA. CSV: data/practice2_retail_eda.csv.

## Запуск
1. Установите Python 3.11 или новее.
2. Откройте корневую папку проекта в VS Code.
3. Установите зависимости: `python -m pip install -r requirements.txt`.
4. Откройте `practice_2.ipynb` и выберите установленное Python-окружение.
5. Выполните **Restart Kernel → Run All**.

Пути к CSV заданы относительно папки ноутбука (`../data/...`), поэтому перемещать файлы данных не нужно. Интернет для загрузки данных не требуется.
