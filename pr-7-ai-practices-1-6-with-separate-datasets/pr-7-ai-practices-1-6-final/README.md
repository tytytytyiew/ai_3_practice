# Практические работы № 1–6 по машинному обучению

**Студент:** Конурбаев Барсбек Искендерович  
**Уровень:** B

Каждая работа находится в собственной папке `practice-1` … `practice-6` и имеет свой `README.md`, notebook и отдельный датасет. Все CSV включены в папку `data/`; загрузка наборов данных из интернета при запуске не требуется.

## Состав
| Работа | Тема | Датасет |
|---|---|---|
| 1 | Настройка окружения и первичный осмотр | Wine Recognition |
| 2 | EDA | Retail EDA с пропусками и выбросами (синтетический) |
| 3 | Предобработка и ColumnTransformer | Customer Churn (синтетический) |
| 4 | Регрессия, мультиколлинеарность и остатки | Diabetes regression |
| 5 | Классификация, ROC/PR и подбор порога | Breast Cancer Wisconsin |
| 6 | Очистка текста и TF-IDF | SMS-корпус (синтетический) |

## Установка
```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```
Откройте нужный ноутбук в VS Code/Jupyter и выполните все ячейки сверху вниз.

## Важно о данных
Практики № 2, 3 и 6 используют явно обозначенные синтетические учебные данные. Практики № 1, 4 и 5 содержат локальные CSV-копии стандартных наборов из scikit-learn. Результаты и ограничения моделей следует интерпретировать в рамках учебной задачи.
