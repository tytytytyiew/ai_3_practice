# Датасеты

- `practice1_wine.csv` — Wine Recognition, локальная копия из scikit-learn.
- `practice2_retail_eda.csv` — синтетические продажи; намеренно добавлены пропуски и выбросы.
- `practice3_customer_churn.csv` — синтетические данные клиентов для демонстрации предобработки.
- `practice4_diabetes.csv` — Diabetes regression, локальная копия из scikit-learn.
- `practice5_breast_cancer.csv` — Breast Cancer Wisconsin, локальная копия из scikit-learn.
- `practice6_sms_messages.csv` — синтетические учебные SMS-сообщения ham/spam.

CSV-файлы находятся в репозитории, поэтому ноутбукам не нужно скачивать данные из сети. Синтетические наборы не следует выдавать за реальные наблюдения.
