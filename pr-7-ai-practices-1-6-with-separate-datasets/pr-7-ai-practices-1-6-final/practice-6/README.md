## Цель
Классификация текстов. Работа выполнена в Jupyter Notebook с последовательными шагами, графиками и выводами.

## Датасет
SMS classification: локальный учебный корпус из 600 синтетических коротких сообщений с метками ham/spam. CSV: data/practice6_sms_messages.csv. Предобработка, TF-IDF, наивный Байес и анализ до пяти ошибок. Корпус синтетический, не реальный пользовательский SMS-архив.

## Запуск
1. Установите Python 3.11 или новее.
2. Откройте корневую папку проекта в VS Code.
3. Установите зависимости: `python -m pip install -r requirements.txt`.
4. Откройте `practice_6.ipynb` и выберите установленное Python-окружение.
5. Выполните **Restart Kernel → Run All**.

Пути к CSV заданы относительно папки ноутбука (`../data/...`), поэтому перемещать файлы данных не нужно. Интернет для загрузки данных не требуется.
