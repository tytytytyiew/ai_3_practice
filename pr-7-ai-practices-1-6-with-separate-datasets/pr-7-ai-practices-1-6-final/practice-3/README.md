## Цель
Пайплайн предобработки. Работа выполнена в Jupyter Notebook с последовательными шагами, графиками и выводами.

## Датасет
Customer Churn: 700 учебных записей клиентов с числовыми и категориальными признаками, пропусками и целевой переменной churn. Данные синтетические. CSV: data/practice3_customer_churn.csv.

## Запуск
1. Установите Python 3.11 или новее.
2. Откройте корневую папку проекта в VS Code.
3. Установите зависимости: `python -m pip install -r requirements.txt`.
4. Откройте `practice_3.ipynb` и выберите установленное Python-окружение.
5. Выполните **Restart Kernel → Run All**.

Пути к CSV заданы относительно папки ноутбука (`../data/...`), поэтому перемещать файлы данных не нужно. Интернет для загрузки данных не требуется.
